# simple-memo

## 실행
https://kimsb69.github.io/simple-memo/ 에서 이메일·비밀번호로 회원가입하면 바로 로그인됩니다. 메모 내용을 입력하고 저장하세요. 삭제 및 로그아웃 버튼을 사용할 수 있습니다.

## 검증 결과
2026-10-30 실제 배포 사이트에서 첫 화면, 회원가입·자동 로그인, 메모 저장·목록, 새로고침 후 로그인·메모 유지, 삭제, 로그아웃·재로그인을 확인했습니다. DB 실제 저장과 RLS 활성화를 확인했고 다른 사용자 역할의 조회·대리 추가·삭제 차단 테스트를 통과했습니다. 공개용 키만 사용합니다.
